# Getting help

- **A question, a bug or an idea about a project:** open an issue on that project's repository. Search the existing issues first.
- **A security problem:** do not open an issue. Follow SECURITY.md.
- **Anything else** (press, collaboration, or something that fits no repository): info.ineedinfo@proton.me

We are a small team and answer as we can, so please be patient.
