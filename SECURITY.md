# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

- Email **info.ineedinfo@proton.me** with the subject "Security: <project name>".
- Or, where the repository has it enabled, use GitHub's private vulnerability reporting (the Security tab of the repository).

Please include the project and version, what you found, how to reproduce it, and what you think the impact is.

## What to expect

We are a small team. We will read every report and reply as soon as we can, but we do not promise a fixed response time. We will tell you whether we accept the report, and credit you in the fix if you want that.

## Supported versions

Only the latest release of each project receives security fixes.

## Scope

Our tools are designed to ask before they change anything on a machine, to collect no telemetry, and to be undoable. A bug that breaks any of these promises is in scope, even if it looks small.
