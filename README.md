# .github

This repository holds the organization-wide files for [INeedInfo](https://github.com/INeedInfo):

- `profile/README.md`: the public organization profile.
- `SECURITY.md`, `CONTRIBUTING.md`, `SUPPORT.md`: default community files that apply to every INeedInfo repository without its own copy.

It is not a product repository. Our projects are listed on the [organization page](https://github.com/INeedInfo).
